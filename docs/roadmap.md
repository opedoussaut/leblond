# Roadmap

## V1 — FIRST CLIMB + CONNECT (this release)

Closed-beta auth, onboarding, Arkose / Climbing District / Font grading, live sessions, attempts, media, projects, deterministic progress analytics, Patrick, FIT import, truthful COROS/Suunto/Garmin adapters, PWA, RLS, tests and CI.

## Milestone 2 — ROAD TO TARGET

Richer working-level views per system, style and wall-angle analysis, normalised cross-gym analysis as estimate coverage grows, Patrick training recommendations, better progress dashboard, wearable trend overlays.

## Milestone 3 — VISION

Photo analysis, selected video-frame analysis, movement annotations, problem recognition help, Patrick visual coaching, video comparison. (Media metadata — duration, dimensions — is already stored.)

## Milestone 4 — SYNC

COROS / Suunto / Garmin production sync (webhooks/pull once approved), Strava OAuth + activity sync with cross-provider de-duplication, deeper Arkose / Climbing District integration if an authorised API appears. Offline session logging.

## Later — not built now

Block’Out deeper integration, friends and shared/live sessions, comments, likes, leaderboards, public profiles, gym maps, Fontainebleau/outdoor database, Apple Health, Google Health Connect, coach voice mode, advanced training plans, notifications, AI video comparison, MCP server, public API.
